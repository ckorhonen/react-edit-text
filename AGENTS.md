# react-edit-text

`src/` contains the editable text and textarea library; `example/` is the CRA demo. Use Node versions supported by `package.json`, run root `npm install` and `npm run build`, then use `cd example && npm install && npm start` for demo work.

Run `npm run test` for unit, lint, and build checks; completion includes the relevant public API behavior and coverage threshold. `npm run test:watch` is interactive. `deploy` publishes the demo and `semantic-release` publishes packages; do not run either for validation.
